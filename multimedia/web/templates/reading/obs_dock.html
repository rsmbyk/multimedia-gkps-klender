{% load static %} {% comment %} The operator dock (spec 119): pick a Tata Ibadah, browse it, and run it. Two views of one panel, built to the approved mockup (v70): the picker is an age-grouped list of services (flat rows — name, an "On screen" pill, a "Today" pill on the day's own rows, a short date) under the same four buckets the reading sidebar draws (spec 132); the runner is a numbered list of entries — songs showing their reference beside the title with a "Bait …" line under it, untitled text in quiet italics, a section break as a hairline — with the current entry pinned, the next one named under it, and a transport row (edition chip, bait strip, two arrows) at the foot. The display state is browser-local (web/display.js): the picker says which service is on screen, the runner says which entry and screen, and the slashed-eye button in the runner's head is the whole display control ("Display this service" / "Hide words"). The dock owns the transport keys and the focus: every control is tabindex="-1" and the panel itself is the focus target (tabindex="-1"), so keys never land on a button and Space never presses whatever was last clicked. {% endcomment %} {{ page_title }}
