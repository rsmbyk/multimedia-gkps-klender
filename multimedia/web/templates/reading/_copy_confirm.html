It names what the copy will be called, because a copy that silently keeps the source's name leaves two records sharing one name (spec 215 US2).{% endcomment %}

Copy as template?

A new template from this Tata Ibadah — same entries, in the same order. The one you are editing does not change.

  • No service date. A template is not tied to a day.
  • Stays a template. It can never become a normal Tata Ibadah.
  • Can be copied again. Copying does not use it up.
