Hover either row. At rest the badge paints exactly as spec 132 accepted; while the edit/delete controls are revealed the badge is not painted — the same rule the date has followed since spec 190. The badge stays in the row's accessible label.

US5 — a song lyric never paints more than two visual lines

Left: a lyric that already fits paints at the accepted size (72px at 1080p — scaled here to the 480×270 fixture). Right: a lyric whose lines would wrap shrinks its type until the block fits two visual lines. The fit changes only font-size; the look (weight, outline, inset, centring, balance) is untouched.
