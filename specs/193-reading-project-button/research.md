Every decision below was settled by reading the code at `9a556a99`; no owner question was needed.

| # | Decision | Rationale | Alternatives rejected | Provenance |
| --- | --- | --- | --- | --- |
| D1 | The click handler is a **delegated** branch in `display.js` for `[data-project-goto]`, sharing the private `openProjector(url)` helper | `display.js` already owns the named-window act (`[data-project-window]`, spec 141) and documents that the shell swap (`reading.js applyPage`) replaces the button's node — a handler bound to the node dies on the click-through path; delegation + `shell:page` is the established answer | A per-node binding in a new module (dies on the swapped stage); a new `reading-project.js` (a second state module for one verb) | `static/web/display.js:280-330`, header comment; `reading.js:1818` (`shell:page`) |
| D2 | The pointer is written through the existing verbs — `goTo(goto)` for a new detour, `resume()` when this detour is open but the words were hidden (A8) | Both are exported (`window.gkpsDisplay.goTo/stepGoto/back/resume`, spec 185); `resume` exists exactly for "words back on, in place" and must never end a go to | A bespoke `write()` call (duplicates `goTo`'s `on: true` and broadcast contract) | `display.js:186-214`, `window.gkpsDisplay` export block |
| D3 | The **content-match skip lives in the reading handler, not in `goTo`** — re-picking the same song from the dock's find band stays an explicit restart (its result is chosen fresh each time) | The owner's ruling scopes the behaviour to the reading pages' controls ("the ones in songs and bible chapter pages"); `dock/R1` names the dock's own contract ("at its first screen or verse") | Putting the skip inside `goTo` (would change the dock's re-pick semantics without a spec) | `docs/spec/dock.md` R1; owner ruling 2026-11-14 |
| D4 | **Content** match means the stored `goto` opens the same song (`kind:'song'`, same `song_id`) or the same chapter (`kind:'passage'`, same `book_id`+`chapter`) — position (`index`/`verse`) and translation do not break the match | The owner's rule is about not disturbing the detour already open; a dock verse-move of the same chapter must keep repainting, so position cannot be part of the skip test on the sender | Matching the whole pointer (a dock verse-move of the same chapter would be skipped on the reading page) | owner ruling ("only fetch … if it is different than the current open goto detour"); `display.js:24-49` (`gotoOf`) |
| D5 | The projector guard (FR-008) is a **module-level applied-pointer** in `projector.js`'s `applyGoto()`: a pointer that deep-equals the last applied one returns before the fetch; `leaveDetour()` (Back) clears it | `applyGoto` is the single choke point every Go To path reaches (boot, channel, the page's own navigation); deep-equal keeps the dock's verse moves alive while making a re-send inert; Back must re-arm so a fresh detour repaints | Key-level guard (would kill verse stepping); sender-side only (the dock could still double-send) | `projector.js:1395-1433` (`applyGoto`), `:1452-1469` (`leaveDetour`), `:1739-1770` (channel handler) |
