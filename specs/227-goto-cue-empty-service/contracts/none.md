# Contracts: A Go To still names itself with no service under it

`none` — no HTTP, model, script or event interface changes.

The Go To continues to travel as one `{type: 'goto'}` message and one `gkps-display.goto` field.
The corner cue's DOM (`#cue-prefix`, `#cue-baits`, `#cue-next-name`) is unchanged; only its
contents in the empty-service state change.
