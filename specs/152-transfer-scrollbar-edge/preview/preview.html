Look closely — the bar's right edge

The number this slice is about is painted, not in the DOM: the page can report the list's box, only the probe can read the bar. Run preview/probe.py for the painted gap in both columns (it opens this file in a headed Chromium, because the headless one paints overlay scrollbars and no bar at all).

What this page is, and what it is not

The two dialogs are the product's own markup — .media-library__dialog, .media-transfers__dialog, .media-transfers__list, the real rows and age headings — drawn with assets/: copies of static/styles/design/{fonts,tokens, components}.css as of 24a6d6d2. The After column adds one scoped rule, which is the whole of the slice.

It is not the app: the rows are written into the page rather than fetched from the companion, and the dialog is placed in the flow instead of being opened with showModal(). The live check is the same dialog on the running dev server (see the README).
